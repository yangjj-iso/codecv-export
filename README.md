# CodeCV Export

把 CodeCV 编辑页中当前可见的简历预览复制到独立打印页，通过浏览器保存为 A4 PDF。脚本在副本中移除带有 `watermark` 类名或 ID 的元素，不修改正在编辑的简历。

## 安装

1. 在浏览器安装 [Tampermonkey（篡改猴）](https://www.tampermonkey.net/)。
2. 打开 [codecv-export.user.js 安装链接](https://github.com/yangjj-iso/codecv-export/raw/refs/heads/main/codecv-export.user.js)，在扩展弹出的页面中选择「安装」。
3. 打开或刷新 CodeCV 简历编辑页，右下角会出现「打印简历 PDF」按钮。

如果安装链接显示源码或下载文件，可在 Tampermonkey 中选择「添加新脚本」，删除默认内容，粘贴 [`codecv-export.user.js`](./codecv-export.user.js) 的完整内容并保存。

> 原来的 `脚本.txt` 已整理为标准 `.user.js` 文件。已安装旧版时，可直接替换旧脚本的全部内容；不要同时启用两个版本。仓库更新发布前，请先使用本地文件内容安装。

不需要安装 Node.js、运行构建命令或配置 API Key。脚本匹配 `https://www.codecvcv.com/*` 和 `https://codecvcv.com/*`，以支持从首页直接切换到编辑页；按钮仅在 `/cv`、`/cv/…` 路径显示。

## 使用

1. 打开自己的简历，等待预览、头像和字体加载完成。
2. 点击「打印简历 PDF」。脚本等待打印页的样式、字体和图片就绪，最多等待 15 秒；加载失败或超时会提示重试。
3. 在浏览器打印窗口选择「另存为 PDF」，核对分页和内容后保存。

建议打印设置：

| 设置 | 建议值 |
| --- | --- |
| 目标打印机 | 另存为 PDF |
| 纸张 / 方向 | A4 / 纵向 |
| 边距 | 无（模板自身的内边距仍会保留） |
| 缩放 | 100% |
| 页眉和页脚 | 关闭，避免附加网址、日期 |
| 背景图形 | 开启，保留模板底色 |

文件名由浏览器根据页面标题建议，可在保存时修改。脚本会打开系统打印流程，不会自动下载 PDF。

## 实现与边界

- 优先查找可见的 `.preview-cv .re-render`，再尝试 `.re-render`。
- 复制页面样式及预览的祖先容器，保留模板选择器、继承样式和 CSS 变量；不复制编辑器的其他内容。
- 移除外层缩放、滚动裁切和阴影，按 A4 宽度排版，保留模板原有分页规则。
- 复制图片与 canvas 位图；清理副本中的脚本、内嵌页面和内联事件。
- 打印结束后清理临时 iframe。如果浏览器不触发 `afterprint`，在下次打印或离开页面时清理，最多保留一个打印页。
- 支持单页路由切换和 body 重建；准备期间禁用按钮，避免重复创建打印任务。

脚本没有引入第三方运行时库，也不调用简历上传或导出接口。打印副本会按原页面地址加载样式、字体和图片，因此可能产生与原站点或其资源 CDN 的网络请求。

这不是 CodeCV 官方导出功能。只处理当前页面已经渲染的预览；水印清理依赖 DOM 标记，不能移除已经合成到图片或 canvas 中的水印。模板结构、站点选择器或浏览器打印行为变化时，可能需要适配。CSS 背景图、视频帧和 Shadow DOM 内容不在资源等待与复制的完整支持范围内。

## 常见问题

**没有按钮**：确认脚本已启用、当前地址是以上域名的 `/cv/…` 编辑页，然后刷新。若扩展提示需要允许用户脚本运行，请按 [Tampermonkey 官方 FAQ](https://www.tampermonkey.net/faq.php) 为当前浏览器完成设置。

**提示找不到预览**：等待简历完成渲染，并确保预览面板可见。若仍失败，站点可能更改了 DOM 结构，需要更新脚本中的 `findPreview()` 选择器。

**样式、图片、字体加载失败或超时**：等待网站资源加载完成后重试，检查网络是否正常。开发者工具控制台中的 `[CodeCV print]` 日志包含错误信息。

**颜色不对、空白页或分页不合适**：先检查背景图形、纸张、边距和缩放设置。脚本保留模板的分页样式，但不能保证所有模板与官方导出完全一致；较长的内容可先在编辑器中调整分页。浏览器扩展、跨域资源限制也可能影响结果。

**提交问题**：到 [Issues](https://github.com/yangjj-iso/codecv-export/issues) 提供浏览器及扩展版本、模板名称、复现步骤和经过脱敏的截图。

## 开发与验证

需要 Node.js 20 或更新版本。用户安装脚本不需要这些步骤。

```sh
npm ci
npx playwright install chromium
npm run check
npm test
```

也可使用本机已安装的 Chrome：

```sh
PLAYWRIGHT_CHANNEL=chrome npm test
```

自动化测试在本地模拟编辑页中检查打印副本、资源等待、错误恢复、路由切换和清理逻辑。测试替换 `window.print()` 以检查打印调用，不会弹出系统打印窗口；这不能替代 Tampermonkey 安装验证、真实账号中的模板验证和最终 PDF 目测。

发布前手动检查：安装脚本，分别打开带头像、中文字体和多页内容的简历，保存 PDF 核对排版；取消打印后再次打印，并检查首页进入编辑页及前进/后退时按钮的显示。
